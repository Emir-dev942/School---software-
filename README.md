# School Management System

A multi-tenant school management system built with PHP and MySQL.

## Features

- Student management
- Fee tracking and debtors list
- Report card generation
- Exam question bank
- Parent portal
- Activity logs
- Backup and restore

## Built With

- PHP
- MySQL
- HTML, CSS, JavaScript

## Status

Working system. Currently used by schools in Nigeria.
